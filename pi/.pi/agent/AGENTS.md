# This machine

Desktop customizations (Hyprland, Omarchy, Ghostty, user services, ~/.local/bin)
live in the dotfiles repo `~/src/github.com/GoodForOneFare/dotfiles` and are
symlinked into `$HOME`. Whenever you use the `omarchy` skill or change anything
under `~/.config`, also load the `dotfiles` skill. It explains where the change
belongs and how to validate, commit and push it.
